# CruDoc Dashboard Redesign — Design Spec

Design name: **Calm Clinical**. Identity colour: **Ink Blue `#3155E0`**.
Reference screens: `screens/day.png`, `screens/evening.png`, `screens/system.png`.
Exact markup for every value below: `reference/*.html` (open in a browser; fonts load from `fonts/`).

The dashboard answers one question a doctor has every few minutes: **"Who's next, and what must I know before they walk in?"** Everything else is ranked by how often and how urgently it is needed.

---

## 1. Non-negotiable rules

1. **Colour means something, always.** No colour is decorative.
   | Colour | Meaning | Never used for |
   |---|---|---|
   | Ink Blue | Brand, the one primary action, "happening now", progress | Status, decoration, charts other than "today" |
   | Amber | Someone is waiting / needs attention soon | Errors |
   | Green | Done / completed / money up | Buttons |
   | Red | **Allergies and patient-safety only** | Validation errors in non-clinical forms, "delete" styling on the dashboard |
   | Violet (AI) | Anything generated by AI | Anything not generated by AI |
   | Teal | Lab results | — |
2. **No other blue** anywhere in the product. A second blue dilutes the identity.
3. **One filled button per region.** The filled button is the next clinical action.
4. **Never show fabricated data.** If a value isn't backed by real data, hide that element. No placeholder numbers, no sample insights. (The current "AI Smart Insights" are static text — remove them unless computed from real records.)
5. **Numbers use tabular figures** (`FontFeature.tabularFigures()`) everywhere: times, counts, rupees, vitals.
6. **Radii follow the concentric rule.** Inner radius = outer radius − inset distance.

### 2.4 Shape
| Element | Radius |
|---|---|
| Cards | 24 |
| Anything inset 12 px inside a card (rows, inner panels, full-width buttons), buttons, inputs | 12 |
| Icon tiles (36 px) | 10 |
| App mark (30 px) | 9 |
| Segmented control outer / inner | 11 / 8 |
| Chips, pills, capsule buttons, avatars | fully round |

Use continuous (Apple-style) corners: `RoundedSuperellipseBorder` if the project's Flutter version has it, otherwise `RoundedRectangleBorder`.

### 2.5 Space
4-pt grid: 4, 8, 12, 16, 20, 24, 32. Card padding 20–24. Gaps between cards 20. Main column stack gap 22.

### 2.6 Depth (elevation = importance)
- Canvas: flat.
- Card (day): 1 px hairline border + `BoxShadow(color: 0x0A101828, blurRadius: 2, offset: Offset(0,1))`.
- Up next card (day): no border; shadows `0x332542BD blur 2 offset (0,1)` and `0x992542BD blur 40 spread −24 offset (0,24)`.
- Evening: no shadows anywhere. Surfaces separate by lightness; Up next gets a 1 px white-6% border.

## 4. Components

**Sidebar** (no card behind it; sits on canvas)
- App mark: 30 px, radius 9, accent fill, white plus (stroke 3.4). Wordmark "CruDoc" 17/600.
- Clinic switcher: surface, hairline, radius 14. Letter tile 32 px (accentTint/accentText), clinic name 14/600, specialty 12.5 label2, up-down chevron. **Replaces the old Specialty Mode card and Switch Specialty button.**
- Groups: **Today** (Dashboard, Queue, Appointments), **Patients** (Patients, Scribe), **Clinic** (Inventory, Revenue, Campaigns). Group label 12/600 label3.
- Item: 40 px tall, radius 12, icon 20 (stroke 1.7, label2), text 14.5/500. Selected: sidebarSelected fill + card shadow + hairline ring, icon in accent, text 600.
- Queue item shows amber 6 px dot + waiting count when > 0.
- Footer: "Free trial · N days left" + "Upgrade" link (12.5); profile row (34 px monogram, name 13.5/600, "Account & settings"). The mobile-app download promo moves into the account menu.

**Header**
- Date line 13.5/500 label2 (evening: moon icon + "· Evening session"). Greeting largeTitle: Good morning (< 12:00), Good afternoon (12–17), Good evening (≥ 17).
- Search field 300×40, radius 12, placeholder "Search patients or ask CruDoc", shortcut hint "Ctrl K" (⌘K on macOS). **This replaces the floating chatbot button.**
- Buttons 40 px: "Add patient" (surface, hairline) and "New visit" (accent fill). **These replace the Quick Actions card.**

**At a glance** (one card, 4 equal cells, inset vertical separators)
1. Seen today: 52 px progress ring (track + accent, stroke 6, round caps), "5 of 13", "8 still to see".
2. Waiting now: count, amber dot + "Average wait N min".
3. Follow-ups due: count, "This week · N overdue".
4. Collected today: ₹ amount, "↑ ₹600 vs last Wednesday" (compare with the same weekday last week; arrow + figure in greenText, or redText if down).

**Up next** (the signature element — ink surface)
- Row 1: "Up next" (600) · "Token 7" (label2) … wait pill (clock icon + "Waiting 8 min").
- Row 2: 56 px monogram + name (title) + "23 y · Female · Returning · Last visit 14 Aug, <last diagnosis>".
- "Reason for visit" label + body text.
- "Alerts and vitals" label + "Recorded 11:41 by front desk" (right). Chips (30 px): allergy chip first (white, red text, warning icon) or "No known allergies" (inset, check icon); then BP, Temp, SpO₂, Weight as inset chips with label2 label + value.
- Actions (44 px): "Start consultation" (white fill, ink text), "View history" (inset), "…" icon button (44×44, aria/semantics label) for reschedule / no-show.
- Up next = earliest *waiting* visit. If nobody is waiting: neutral surface card "No one waiting · next booking at 12:30" with a secondary "New visit" button. Don't show an empty ink card.

**Today's schedule** (card, padding 20/12/12)
- Header: "Today's schedule" + "13 appointments · 9:30 AM to 6:10 PM"; segmented control: All | Waiting n | Done n (36 px, inset track, selected segment raised).
- Completed visits collapse into one 48 px inset row: green check + "5 seen this morning" + first names + "Show ⌄" (expands in place).
- A future session (e.g. evening while it's still morning) collapses the same way with a moon icon.
- Visit row, 60 px: time (15/600, AM/PM micro label3, width 64) · 8 px status dot · 34 px monogram · name 15/600 + "45 M" 13 label2 / reason · visit type 13 label2 · right-aligned status.
  - In consultation: row fill accentWash, time in accentText, accent dot, pill "In consultation" (accentTint/accentText).
  - Waiting: amber dot, "Waiting · 8 min" amberText 600.
  - Booked: hollow 1.5 px label3 ring, "Booked" label3.
- Separators are inset to start at the text column (160 px from the card's inner edge), not full width.
- Monograms are grey (track + label2), never coloured, so they never compete with status colours.
- End of list (evening): "That's the last booking for today." + "Add a walk-in" link.

**Needs attention** (day only; hide when empty, max 3)
- Row: 36 px icon tile (tinted by category: labs teal, follow-ups amber, stock neutral) + title 14/600 + sub 13 label2 + capsule action button (30 px, inset fill, accentText 600: "Review", "Call", "Reorder").
- **Replaces Activity Logs** on the dashboard (logs move to their own screen).

**Insights** (AI — violet only; hide when there are none; max 2)
- Header: sparkle icon + "Insights" … "CruDoc AI" (ai colour).
- Each insight: aiTint panel, radius 12, text 14/20, then basis line ("Based on the last 6 weeks") + action link in ai colour.
- Footer 12 label3: "Suggestions only. Review before acting."

**Collections**
- "Collections" … "Last 7 days"; total (metric); "UPI ₹x · Cash ₹y".
- 7 bars (24 px wide, radius 6, max 80 px): past days in track colour, today in accent with a value label above ("₹3.4k"). Closed days are a 4 px stub.

**Wrap up the day** (evening only; replaces Needs attention + Insights)
- Title + "2 patients left · clinic closes at 8:00 PM".
- Rows (same pattern as Needs attention): prescriptions to sign (Sign), overdue follow-ups (Call), match today's cash (Match), tomorrow's bookings (View).
- Full-width 44 px tinted button "Close the day" (accentTint/accentText) — not filled, because the filled action is still "Start consultation".

## 5. Behaviour

- **Appearance:** Auto (default) switches to Evening from the clinic's evening-session start (default 17:00) until closing, otherwise Day. Settings offers Auto / Day / Evening.
- **Motion:** 200–250 ms, `Curves.easeOutCubic`, for expand/collapse and hover. Press feedback scale 0.98. No bounce. Respect reduced-motion settings.
- **Hover (desktop):** rows get an inset fill; buttons darken ~6%.
- **Keyboard:** Ctrl/⌘ K focuses search; Enter on Up next starts consultation.
- **Live updates:** waiting times and counts update without layout shift (fixed row heights, skeletons while loading).
