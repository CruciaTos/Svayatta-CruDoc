# CruDoc Patients redesign — handoff

1. Copy this folder into the repo as `design/patients-redesign/`.
2. Open Claude Code in auto or accept-edits mode (Shift+Tab to cycle).
3. Paste the prompt in `PROMPT.md`.

| Path | What it is |
|---|---|
| `PROMPT.md` | The prompt for Claude Code, including all behaviour |
| `screens/` | Target screenshots for every state, 1440 px wide |
| `html/PatientsHybrid.dc.html` | Patients list prototype (table and split modes) |
| `html/Patient.dc.html` | Patient details |
| `html/PatientsFirstWeek.dc.html` | First-run state |
| `html/Patients.dc.html`, `html/PatientsPreview.dc.html` | Static snapshots of the two list modes |

Tokens, fonts and design rules come from the dashboard handoff already in the repo (`design/dashboard-redesign/`, `.claude/rules/crudoc-ui.md`).
